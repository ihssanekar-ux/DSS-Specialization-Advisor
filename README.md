# DSS-Specialization-Advisor
A Decision Support System to help university students choose the most suitable academic specialization using the WSM method.

## Project Overview

This project aims to develop a web-based Decision Support System (DSS) that helps university students identify the most suitable academic specialization.

The system compares four academic specializations using multiple evaluation criteria and applies the Weighted Sum Model (WSM) to calculate scores and rank the available alternatives.
