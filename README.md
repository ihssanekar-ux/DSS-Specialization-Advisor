# DSS-Specialization-Advisor
A Decision Support System to help university students choose the most suitable academic specialization using the WSM method.

## Project Overview

This project aims to develop a web-based Decision Support System (DSS) that helps university students identify the most suitable academic specialization.

The system compares four academic specializations using multiple evaluation criteria and applies the Weighted Sum Model (WSM) to calculate scores and rank the available alternatives.

## Problem Statement

Choosing a university specialization can be a difficult decision for students because several factors need to be considered simultaneously.

Students may find it challenging to compare different specializations based on their academic skills, personal interests, career opportunities, and other relevant criteria.

Therefore, a structured decision-support approach is needed to evaluate the available alternatives and help students identify the specialization that best matches the defined evaluation criteria.

## Project Objectives

The main objectives of this project are:

- To develop a web-based Decision Support System for university specialization selection.
- To evaluate the available academic specializations based on predefined criteria.
- To apply the Weighted Sum Model (WSM) to calculate the weighted scores of each alternative.
- To rank the available specializations according to their final scores.
- To help students make more informed academic decisions.

## Technologies Used

The project is developed using the following technologies:

- HTML5: To structure the web pages.
- CSS3: To style and design the user interface.
- JavaScript: To add interactivity to the web pages.
- PHP: To handle server-side operations, database communication, and the WSM calculations.
- MySQL: To store and manage the system's data.

## Project Structure

The project is organized into the following directories:

- `docs/`: Contains project documentation and system diagrams.
- `frontend/`: Contains the HTML, CSS, and JavaScript files.
- `backend/`: Contains PHP files responsible for server-side operations and the WSM implementation.
- `database/`: Contains SQL files for database creation and management.
- `report/`: Contains the final project report.
